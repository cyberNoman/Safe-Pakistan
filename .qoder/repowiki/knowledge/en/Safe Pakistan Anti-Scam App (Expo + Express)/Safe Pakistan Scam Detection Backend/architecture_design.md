Single-file Express server (`index.js`) exposing three POST endpoints: `/analyze/text` performs scam classification via a tiered model pipeline — first tries the fine-tuned `FT_MODEL` from `.env`, falls back to `MAX_MODEL` (`qwen-max`), and finally degrades to a local regex rule engine (`localRules`) if both LLM calls fail. The LLM call targets DashScope's text-generation endpoint using a fixed `SYSTEM_PROMPT` that constrains output to a JSON schema with verdict, risk_score, confidence, scam_type, evidence_spans, and multilingual explanations. Additional endpoints provide device pairing (`/family/pair`) and mock push notification delivery (`/alerts/guardian`). Configuration is loaded from `.env` via `dotenv`; CORS and JSON body parsing are applied globally. `test.js` is a standalone fetch-based smoke test against the running server.
