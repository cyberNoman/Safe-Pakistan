The module is organized into four folders that form a clear layering:
- `navigation/AppNavigator.js` is the single entry point that wires `@react-navigation/native-stack` and `@react-navigation/bottom-tabs` into a root `NavigationContainer`. A top-level native stack holds onboarding (`Welcome`) and full-screen flows (`Verdict`, `Voice`, `FamilyConsent`, `ScreenshotResult`, `ModelPerf`, `Library`), while a bottom tab navigator groups the five main destinations (`Home`, `Scan`, `Family`, `Report`, `Chat`).
- `screens/` contains one functional component per route; screens are presentation-only and consume navigation props from React Navigation.
- `components/` holds shared presentational primitives: `Cards.js` (Avatar, StatCard, SectionHeader, ActivityFeedItem, FamilyMemberCard, LanguageChip, EmptyState), `Indicators.js` (StatusPill, VerdictBadge, AgentStatusDot), `Overlays.js`, and `ThreatRing.js` — an animated SVG progress ring built with `react-native-svg` + `react-native-reanimated`.
- `theme/` is the design-token layer: `tokens.js` centralizes colors, gradients, font families, spacing, radii, shadows, motion timings; `typography.js` exports prebuilt `TextStyle` objects via `en()` and `ur()` helpers that enforce Urdu rules (+2px size, RTL, 1.8× line-height). All screens and components import exclusively from `@/theme/tokens` and `@/theme/typography`, never hard-coding values.
Dependency direction is strictly one-way: screens → components → theme; navigation imports screens but nothing else depends on it.
