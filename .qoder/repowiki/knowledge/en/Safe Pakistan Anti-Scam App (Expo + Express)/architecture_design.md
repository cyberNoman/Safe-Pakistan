Two sibling services share one repository: the `frontend` child is an Expo SDK 52 app whose `App.js` bootstraps fonts and mounts `src/navigation/AppNavigator`, while the `backend` child is an independent Express server. The two communicate over HTTP — the frontend calls `https://sentinel-pk-api-315679408915.asia-south1.run.app/analyze` with `{ text, lang }` and renders the returned `{ verdict, score, confidence, type, redFlags }` on the Verdict screen. There is no shared code or runtime between them; coupling is purely the REST contract defined in the README's wiring section. Build and run are split: `npx expo start` launches the mobile UI, and the backend runs separately as its own Node process.
