03 · Interface

API Contract

{
  "verdict": "scam",
  "score": 96,
  "confidence": 95,
  "type": "BISP 8171 Fraud",
  "redFlags": ["OTP", "foran", "account band"],
  "explanation_en": "...",
  "explanation_roman_ur": "...",
  "explanation_urdu": "...",
  "model_used": "QWEN_MAX"
}
  • Strict shape validation — a malformed payload from any layer cascades to the next layer, never to the client.
  • Provider error bodies never surfaced to the client — failures are absorbed by the cascade.
  • Trilingual explanations ship in every verdict: English, Roman Urdu, Urdu script.

05 · Reliability

Resilience Ladder

01
3-second backend cap — Promise.race
If the LLM is slow, the offline result ships. Latency is bounded, always.
02
1.4s minimum loading dwell
UX choreography always plays — fast backends wait for the animation, never the reverse.
03
DEMO_MODE.offlineOnly kill switch
Zero-network operation on demand — full verdict flow with no connectivity.
04
Graceful degradation
Backend down ⇒ the app never knows.
Rehearsal incident, real evidence: cloud endpoint returned 503 during rehearsal — app verdict unchanged.

08 · Client

Frontend Architecture

  • Expo SDK + React Navigation — native stack + 5 bottom tabs.
  • Reanimated for motion — no core Animated anywhere.
  • react-native-svg ThreatRing — vector threat visualization, resolution-independent.
  • Design tokens are the single source of truth — tokens.js: COLORS / SIZE / RADIUS / SPACE / SHADOW / gradients, plus typography.js.
  • Screens fit 390×844 with designated scrollers only — Analytics, Library, Chat.
  • Safe-area-aware tab bar via useSafeAreaInsets.
09 · Discipline

Design System as Engineering

  • Zero hardcoded hex / radius / spacing outside tokens — enforced by grep gates.
  • Blue-tinted shadows as brand signature.
  • Semantic color law: red = scam verdict ONLY.
  • Urdu typography rules: English size +2, lineHeight ×1.8, RTL Nastaliq — نستعلیق never mixed with English in one Text node.
  • ≥ 44pt hit targets on every interactive element.
  • Verdict text floor 17pt — legibility is a safety property.
  • Export gate — expo export as a CI-style boot check.
10 · Honest Register

Security & Risks

  • No auth / rate-limit on the API yet — P0 post-demo
  • .env keys live server-side only — nothing sensitive ships in the bundle.
  • Data-minimal storage philosophy: we keep verdicts, not raw messages.
  • Conservative verdict bias as the safety default — unsure is suspicious, never safe.
  • Regulatory awareness: PTA / PECA context; consent-gated Family Shield.
