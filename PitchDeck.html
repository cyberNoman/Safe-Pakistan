Honesty · Stress Test

We broke our own model on purpose.

• Run 1: 30% accuracy, 40% false alarms, lost to a regex baseline

• Diagnosis: JSON serialization failure + no sender verification

• Fix: L0 sender prior (never a bypass) + OTP delivery branch + shared rules classifier as the offline floor

• Run 2: 76.3% mean accuracy, 87% scam recall, FPR 14.4%, baseline 46.5%

• Offline: 58.7–61.9%, still above baseline

Honesty

Known limitations — stated plainly.

• L1 JSON parse failure ~55% out-of-distribution — every failure escalates silently and the user never sees it

• Offline safe precision 35–40% — a conservative floor that over-flags

• ±3% accuracy variance, up to ±7% on safe precision

• Suspicious-class recall weak — the smallest training slice; v2 needs more ambiguous examples

• Family alerts need the laptop backend on the same hotspot — Cloud Run does not serve /family/* yet

• The demo APK allows cleartext HTTP to reach the laptop over LAN; production is https. Flagged // DEMO-BUILD

• Real push needs a dev or preview build — Expo Go cannot mint a token, so the app falls back to SMS and says why

• Screenshot analysis is canned — the image is picked for real but the score (91) and findings are stand-ins, badged DEMO · SIMULATED on-screen. Text/SMS analysis is real

• There is no speech-to-text — expo-speech is TTS only. Voice Guardian boots honest, shows no fake waveform, and routes to hint chips that pre-fill the chat

• The sender is never guessed — an ambiguous number like "Rs 25000" is an amount, not a shortcode, and naming it in an NCCIA complaint would be a false accusation
