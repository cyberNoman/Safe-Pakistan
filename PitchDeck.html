Technical Innovation

The 3-layer AI inference cascade.

Layer 1 · hifazat-edge

Fine-tuned Qwen2.5-1.5B-Instruct, trained on Pakistani scam patterns. Runs locally on Ollama. 2.3s, zero cloud cost.

Layer 2 · Qwen-Max

Alibaba Cloud Model Studio. Catches what the small model is unsure about (confidence gate < 70). The teacher, not the workhorse.

Layer 3 · Rule engine

On-device weighted-regex scoring. 0s, works with zero network. The unbreakable floor — the demo can never die.

Verified end-to-end by an automated harness: 4/4 failure scenarios PASS — model down, cloud down, total blackout — every path still returns the correct verdict. Unsure always means suspicious; a user is never told "safe" by accident.
